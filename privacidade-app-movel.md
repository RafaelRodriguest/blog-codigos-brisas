**Última atualização: 03 de setembro de 2026**

Esta Política de Privacidade descreve como o aplicativo **Movel Tracker** coleta, usa e protege as informações dos usuários.

## 1. Dados que coletamos

- **Conta de acesso:** e-mail e senha para autenticação dos usuários operacionais do aplicativo. As senhas são armazenadas de forma criptografada e não temos acesso a elas em texto simples.
- **Localização (GPS):** o aplicativo acessa a localização do dispositivo para registrar e associar a posição geográfica dos sites/torres cadastrados durante o uso operacional.
- **Câmera e fotos:** o aplicativo permite capturar ou enviar fotos relacionadas aos sites/estruturas cadastrados, como parte do fluxo de trabalho operacional.

Não coletamos dados pessoais sensíveis além dos listados acima, e o aplicativo não coleta dados de usuários finais fora do contexto operacional (uso restrito a colaboradores autorizados).

## 2. Como usamos os dados

- Autenticar o acesso ao aplicativo e identificar o usuário responsável por cada registro.
- Associar a localização capturada aos sites cadastrados na plataforma.
- Armazenar as fotos enviadas como evidência/documentação dos sites.

## 3. Compartilhamento de dados

Não vendemos, alugamos ou compartilhamos os dados coletados com terceiros para fins de publicidade ou marketing. Os dados são armazenados em infraestrutura do Supabase (banco de dados e armazenamento de arquivos) utilizada exclusivamente para o funcionamento do aplicativo.

## 4. Armazenamento e segurança

Os dados são armazenados em servidores do Supabase com controles de acesso (Row Level Security) e autenticação. Adotamos medidas técnicas razoáveis para proteger as informações contra acesso não autorizado.

## 5. Retenção e exclusão de dados

Os dados são mantidos enquanto a conta do usuário estiver ativa. Para solicitar a exclusão da sua conta e dos dados associados, entre em contato pelo e-mail abaixo.

## 6. Permissões do aplicativo

O aplicativo pode solicitar as seguintes permissões do dispositivo:

- **Localização:** para registrar a posição dos sites durante o uso operacional.
- **Câmera/Armazenamento:** para captura e envio de fotos dos sites.

Essas permissões são usadas exclusivamente para as finalidades descritas nesta política.
